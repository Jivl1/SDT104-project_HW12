Function Declarations vs Expressions + Hoisting

Function declaration (calculateArea) is hoisted — available before its line.
Function expression (calculatePerimeter, getCalculation) are const — they stay in the Temporal Dead Zone until their line executes, so calling them before their definition throws a ReferenceError.

Scope, Parameters, and this Binding

Default parameters: name = "Guest" is used when no argument is passed.
Regular method: this is bound dynamically — it's the object that called the method.
Arrow method: this is inherited from the enclosing lexical scope (here, global/module), so this.name is undefined.
var is function-scoped and leaks outside the loop block. let is block-scoped and disappears after the loop.
